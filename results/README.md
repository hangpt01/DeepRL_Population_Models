# Small accepted and diagnostic results

- `accepted/`: immutable accepted 144-method-cell table and its receipt.
- `diagnostic_replay/`: M1–M15 comparison and schema report.
- `followups/S2/`: oracle regret/VPI/identifiability results and receipts.
- `followups/H14/`: M13 re-instrumentation table and receipt.
- `followups/reward_screen/`: reward-screen table and receipt.
- `followups/S6/`: completed fit-probe receipt.
- `followups/H12/`: placeholder until the running H12 repair and aggregation finish.

These files are copied byte-for-byte. Canonical scratch paths and SHA-256 hashes
are recorded in `provenance/copied_artifacts.sha256`.
