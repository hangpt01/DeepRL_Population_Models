# Motivation Native Figures

This folder contains the paper-facing figures for
`docs/benchmark/09_motivation_native_results.tex`.

Each figure is saved as both `.pdf` for LaTeX and `.png` for quick inspection.

| Figure | Purpose |
|---|---|
| `moor_native_returns_by_family` | Clean naive-baseline comparison: best general method vs single-Ricker `moor_native`. |
| `headline_returns_by_family` | Best general method vs best native ecological solver, allowing `plus_native` or `moor_native`. |
| `all_methods_returns_by_family` | Direct all-method comparison across dynamics families. |
| `native_gap_by_sigma` | Best-general minus best-native gap across observation-noise levels. |
| `training_dynamics_log_mse` | Train/holdout learned-dynamics log-MSE for `refplan`, `bamcts`, and `ogsrl`. |
| `ogsrl_surrogate_loss` | OGSRL actor surrogate-loss trace over update steps. |
| `search_budget_gap` | Search-budget audit: as-run vs tuned best-general gap relative to native. |
| `danger_zone_action_composition` | Conditional action composition in the danger band, split recoverable vs sink populations. |

All figures are generated by:

```bash
PYTHONPATH=src python scripts/plot_motivation_native_results.py
```
