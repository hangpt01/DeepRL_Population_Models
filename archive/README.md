# Archive

This directory retains superseded code, older experiments, logs, and the
debugging/step-back trail.

- Authored source, configs, tests, and documents are tracked.
- Artifact-only retained material is under `archive/artifacts/` and ignored by
  Git to keep the publishable history small.
- `archive/` as a whole is therefore not gitignored; only
  `archive/artifacts/` is.
- Raw datasets, fit caches, venvs, VCS metadata, and numerical model blobs remain
  excluded according to the approved Phase-1 manifest.
