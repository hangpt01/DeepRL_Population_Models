## P_safe Decision Read

The analysis decision file recommends `P = 5`.

The headline numbers support that as a provisional average-case choice:

- Amur tiger safe mean operational return decreases from P2 to P20: 2.96, 2.43, 1.40, -1.23
- Puerto Rican parrot safe mean operational return decreases more sharply: 2.48, 0.48, -2.63, -8.86
- Egyptian vulture is unsafe at all tested penalties, so increasing P mostly scales penalty domination instead of creating recovery

This matches the intended probe logic: avoid a penalty so small that safe looks like yield, but avoid P20-style over-penalization.

One caution: cell-wise minima remain severe at every tested P. For example, Amur tiger and Puerto Rican parrot have some negative-return cells even at P5. That does not necessarily reject P5, but the final paper/table language should say whether the decision rule is average-case, median/cell-wise, or worst-case.

## What The Artifacts Cannot Yet Prove

The original probe asked for action-preference checks such as whether the vulture prefers translocation-like action `a10`.

The current artifacts are weak for that question:

- `episodes.csv` logs `danger_action_0_fraction` through `danger_action_10_fraction`
- those are only danger-zone action fractions, not whole-episode action histograms
- for populations already below the safety threshold, such as Egyptian vulture, the danger-zone denominator can be uninformative
- no global per-action frequency table was found in the main analysis outputs

So the P5 decision can be locked as a penalty-calibration choice, but a strong sink/action-preference claim needs better action logging or a small targeted re-evaluation.
