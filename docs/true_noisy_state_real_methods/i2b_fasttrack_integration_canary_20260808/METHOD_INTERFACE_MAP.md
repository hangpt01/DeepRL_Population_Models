# I2B fast-track method interface map

This map freezes only source-factual seams. The primary contrast is an end-to-end
method-bundle robustness comparison. Any changed learned artifact or `residual_sigma`
forces `MODEL-FIT AXIS CHANGED — END-TO-END BUNDLE ONLY`. A secondary frozen-fit
diagnostic is optional and cannot be claimed while any applicable identity is unresolved.

Shared general interface evidence: `BeliefState.public_features` is at
`src/tracks/general/real_ecology_benchmark/types.py:121`; the noisy Arm O
`PublicObservationFilter` is at
`src/tracks/general/real_ecology_benchmark/beliefs.py:586`; and evaluator timing is
`ContinuousEvaluator.run` at
`src/tracks/general/real_ecology_benchmark/evaluator.py:31`.

Arm T is not executed in this package. The runtime API has no `next_states` argument,
requires a process-local capability, rejects private/evaluator-only fields, rejects
zero/epsilon sigma or scale, and rejects an Oracle shortcut.
