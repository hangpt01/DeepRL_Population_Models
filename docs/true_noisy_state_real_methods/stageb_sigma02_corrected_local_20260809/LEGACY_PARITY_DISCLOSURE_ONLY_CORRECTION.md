# Legacy parity disclosure-only correction

The 2026-08-08 fast-track canary is permanently retained as historical disclosure. Its
classification remains `LEGACY_INELIGIBLE`; all twelve missing execution-contract bindings
remain explicit and canonically ordered. It is never upgraded, rebound, numerically compared,
or consulted to authorize or reject a current Stage B task.

A fully registered task with no eligible prospective baseline is publishable on its current
scientific evidence: frozen registration and driver inputs, source and driver hashes, frozen
artifacts and replay receipts, registered interpreters and CPU, RNG-v2 evidence, information
boundary, atomic publication, task receipt, and checksums. No same-run replacement baseline is
created.

An external baseline is optional. When supplied prospectively, it must carry the complete
eligible binding, identify a different producer registration and DRIVER_INPUTS document, live
outside the current scientific output root, and satisfy the existing exact and `1e-9` absolute
tolerance comparison contract. Eligibility or value mismatch remains fail-closed and publishes
only the existing collision-safe failure diagnostic.

Every Arm O and Arm T task receipt records `parity_mode`,
`eligible_baseline_supplied`, the historical canary identity, and
`historical_canary_used_for_authorization: false`.

The corrected local test contract contains 351 tests after adding the five adversarial policy
cases in this correction.
